# מבנה הרפו

הרפו מרכז את תוכנית המחקר לתזה/מאמר סביב QA ארגוני, RAG, ומיפוי מקורות הקרקוע הנדרשים למענה.

## מסמך מרכזי
עיקר התוכנית נמצאת ב[[Full|מסמך המידע]].

## רעיון המחקר בקצרה
המחקר בוחן האם בנצ'מארקים ושיטות RAG מבוססי מסמכים מניחים בפועל שמקור הקרקוע הוא בעיקר ראיות טקסטואליות מקומיות, אף שב-QA ארגוני שאלות רבות עשויות לדרוש מטאדאטה, מבנה תיקיות, אונטולוגיה ארגונית או אגרגציה על מידע מובנה.

## מצב נוכחי
השלב הנוכחי הוא תכנון טענה 1 סביב שער ישימות דאטסטים: לפני פיתוח ניסויים מלא, צריך לוודא שיש 6-8 דאטסטים רלוונטיים, ומתוכם 1-2 שמכילים מספיק שאלות אונטולוגיה ארגונית ואגרגציה כדי לבדוק את ההשערה בצורה משמעותית. תחת `hypotheses/hypothesis-1` נמצאים מסמכי התכנון המפורטים.

## חומרי גלם
התיקייה `hypotheses/datasets/deep_research` מכילה סקירות עומק גולמיות ולא מחייבות שנועדו להרחיב את המבט על דאטסטים אפשריים. הן יכולות לכלול רעיונות, מועמדים או ניסוחים שסותרים זה את זה, ולכן החלטות מחייבות צריכות לעבור למסמכי התכנון הרשמיים או לקבצי registry ייעודיים.
